# 拼好课 V2

拼好课是面向北京大学课程的搜索、筛选与树洞课程评测检索工具。生产入口：[https://www.pinhaoke.love](https://www.pinhaoke.love)。项目以只读课程快照为数据源，不提供选课、退课或加入选课计划功能。

## 产品入口与数据范围

| 页面 | 路径 | 内容 |
|---|---|---|
| 课程搜索 | `/` | 2026 春季、暑期、秋季课程搜索、筛选与详情 |
| 树洞课程评测 | `/reviews` | 按课程或教师检索树洞课程评价，并按需查看完整快照树洞 |

课程搜索页的学期选项依次为：

1. 2026 春季学期
2. 2026 暑期学期
3. 2026 秋季学期

秋季为默认学期。春季和秋季同时收录本科生、研究生课程；暑期收录本科生课程。选课系统中的重复挂载会在课程列表合并，因此页面卡片数少于源记录数：春季 `3701`、暑期 `160`、秋季 `4529`。秋季本科以 2026-09-07 快照更新并保留旧快照独有课程，共 3152 条源记录；所有学期均关闭翻译，页面和 API 使用选课网抓取的原始课程字段。

“树洞课程评测”独立入口暂时隐藏，不参与学期切换；已有 `/reviews` 页面、API 与数据保留。数据范围 `2022-12-21` 至 `2026-07-13` 和评测数据量 `90880` 以小字显示在“最新课程评测”标题右侧，后者等于 `47843` 个主题加 `43037` 条相关回复。快照覆盖的这些主题还保存 `210570` 条非空回复，用于完整树洞弹窗；该数量不计入评测数据量。

## 功能

### 课程搜索

- 按课程名、原始英文名、教师、教室或课程号搜索
- 按课程类型、类别、学分、开课单位、星期几、上课节时、成绩记载方式和教室筛选；上课节时的候选项覆盖当前学期出现过的全部节次区间，`1-2`、`3-4` 这类两节课的区间排在最前
- 按课程名、学分、最早节次排序，或使用跨页稳定的随机排序
- 合并选课网中同一教学班的多类别挂载，同时保留完整课程类型和类别徽章
- 查看课程简介、先修课程、教材、参考书、教学大纲、教学评估及研究生详情
- 将搜索、筛选、排序、学期和已打开课程写入可分享 URL；旧语言参数不再改变显示
- 界面固定中文，隐藏语言切换；课程名、职称、院系、时间及详情直接显示原始数据，来源自带的英文名称与简介仍予保留

### 树洞课程评测

- 按课程或教师自动检索，搜索输入经过 `300 ms` 防抖，不需要单独的搜索按钮
- 热度最高的 `24` 门课程只在点击右侧“热门课程”后展开，不显示输入联想
- 列表只展示课程评测主帖及其中具有实际评价信息的回复
- 默认列表把 2026 年质量分最高的 `10` 个评测树洞置顶，其余和搜索结果按时间倒序显示
- 点击卡片后按需读取该树洞在快照中的完整主帖和全部回复；列表筛选口径不会因此改变
- 课程名、教师名、`思修`、`军理`、`高数`、`AI引论` 等常见课程别称，以及 `ZZJ`、`lsj` 等教师姓名拼音首字母都会加粗彩色高亮
- 展示树洞号、评论号、楼层、时间、来源月份和原树洞链接，不展示作者身份或回复关系
- 电话、邮箱、微信和 QQ 等联系方式在入库前清除

### 留言板

- 课程页与评测页右上角的留言按钮打开悬浮留言板，任何人都可以公开留言
- 面板顶部一句话提示：问题反馈、功能建议、想对开发者说的话都可以写在这里，所有人可见
- 留言按时间倒序滚动浏览，支持分页加载更多；单条留言上限 `500` 字
- 每条留言下可回复并展开回复列表，回复支持分页；留言和回复共用每小时 `5` 条、每天 `20` 条的 IP 发布频率限制
- 登录后使用个人昵称，未登录、老账号和旧留言默认显示“路过的 PKUer”；公开内容只保存发言时的昵称，不公开登录用户名
- 面板顶部“更新日志”按钮切换到更新日志子页面，可返回留言板；两页共用 [changelog.json](changelog.json) 中的主要功能与数据更新记录；不收录功能回退、修复和细微调整，重大更新的日期、标题及内容加粗显示

### 访问统计

- 课程页与评测页右上角的统计按钮打开悬浮面板，实时查看网站访问情况
- 展示今日、近 `7` 天、累计的访问量与访客数，以及近 `7` 天每日访问量柱状趋势
- 面板打开时每 `20` 秒自动刷新
- 按北京时间分日统计，同一访客当天多次访问只算一位访客，不收集任何身份信息

### 收藏与账号

- 课程页右上角的账号按钮：未登录显示“登录”，登录后变为“个人”，点击进入页面内全屏的“个人中心”
- 课程卡片右上角和课程详情弹窗各有一个星标按钮，点一下把课程加入默认收藏夹，再点一下取消
- 支持多个收藏夹：每个账号有一个不可删除、可改名的默认收藏夹，还能新建自定义收藏夹，一门课可以同时放进多个收藏夹
- 在课程详情弹窗或个人中心里勾选，即可选择课程加入哪些收藏夹；删除某个自定义收藏夹时，只属于它的课程会一并取消收藏
- 收藏保存在服务器，登录同一账号后手机、平板和电脑看到同一份收藏和收藏夹，实现多端同步
- 账号只需用户名和密码，不收集邮箱、手机号或任何身份信息；用户名为 `3` 到 `20` 位字母、数字或下划线，密码至少 `8` 位
- 个人中心支持修改昵称，默认为“路过的 PKUer”，可设置 `1` 到 `30` 个字；昵称与登录用户名独立，修改用于之后的新留言和回复，历史发言保留当时昵称
- 注册时自定义 `1` 到 `3` 个安全密保问题，忘记密码时答对任意一个即可重置密码；答案不区分大小写和空格
- 必须登录才能收藏：未登录时点击星标会打开登录或注册表单，登录成功后进入个人中心并自动完成刚才那一次收藏
- 个人中心里可以切换查看“全部”或某个收藏夹的课程、新建与管理收藏夹、打开课程详情或移出；课程库更新后收藏自动重新对应到新的课程记录，对应不上的条目保留记录并标注
- 每个账号最多收藏 `300` 门课程、`50` 个自定义收藏夹；个人中心里可修改密码、修改密保或删除账号，删除后收藏、收藏夹与密保一并清除

### 课程留言

- 有课程补充的搜索结果在卡片右下角显示感叹号和“内容有修正”。点开课程后，详情顶部用明亮的完整描边展示最新补充摘要，可补充课程变化、选课提醒和信息修改建议。
- 点击“修正信息”打开悬浮窗，查看全部补充并发布最多 500 字的公开备注，也可回复其他人的补充；登录后显示个人昵称，未登录显示“路过的 PKUer”。
- 留言按实际学期、培养层次、课程号和班号保存，课程 ID 重建或教师变化不会丢失同班讨论；与站点留言板分别展示，共享发布频率限制。

### 我的课表

- 个人中心可切换“我的收藏”和“我的课表”；收藏卡片复用首页样式，直接显示教师、院系、时间和地点，已有收藏自动补齐当前课程字段。
- 在课程详情点击“加入课表”，登录后保存到账号；未登录时先登录并自动补加，跨设备同步。课表独立于收藏，可单独移除课程；再次点击“已加入课表”即可移除。从收藏夹或课表打开课程详情时，直接悬浮在个人中心上，关闭后保留原视图与滚动位置。
- 按学期和周次（含源记录中的第 0 周）查看星期 / 节次表，支持单双周和多段时间；移动端可横向滚动。可能重叠的课程高亮提示，无法识别的时间保留在下方课程列表供核对。
- 课表课程可单独编辑名称、教师、地点、上课时间和个人备注；修改只保存在自己的账号课表中，公共课程库、收藏和其他用户不受影响。支持自定义添加课程、按星期与节次设置多段时间、周次范围和单双周；原始时间文本也可保留。选课网课程可恢复原始信息，自定义课程可切换所属学期。
- 点击课表上方的“导出课表”，下载当前学期、周次的完整 PNG 图片，包含七天、14 节课、课程名称、地点及冲突提示；时间待确认或已失效的课程附在图片下方。图片在浏览器本地生成，不受手机可视范围与滚动位置限制。
- `GET /api/timetable`、`POST /api/timetable`（`id`）、`POST /api/timetable/remove`（`course_key`）均要求登录；写入校验来源并限流，每账号最多 100 门，重复添加不会产生重复记录。
- 个人编辑使用 `POST /api/timetable/update`，恢复原始信息使用 `POST /api/timetable/reset`，自定义课程使用 `POST /api/timetable/custom`。三者均校验登录、来源与记录归属；个人修改、自定义课程、备注随账号同步，并参与周次筛选、冲突检查和 PNG 导出。

### 通用体验

- 支持浅色/深色模式，主题选择保存在浏览器本地
- 支持键盘打开卡片、关闭弹窗、焦点循环与焦点恢复
- 尊重 `prefers-reduced-motion`，关闭持续动画和大部分过渡
- 适配桌面端、平板和手机端；手机端三个学期入口每行两个，树洞课程评测入口暂时隐藏，覆盖 `1440`、`390`、`320` 等典型视口
- 课程页和评测页使用 `AbortController` 与请求序号校验，避免快速输入时旧响应覆盖新结果

## 技术架构

项目没有前端构建步骤，写入接口只有公开留言板、访问统计和账号与收藏三类：

```text
浏览器
  ├─ index.html / reviews.html       原生 HTML、CSS、JavaScript
  └─ GET/POST /api/*                 搜索、筛选、详情、留言、账号、收藏、健康检查
          │
        Nginx                        TLS、静态图片、反向代理
          │
        Uvicorn + FastAPI            参数校验、查询合并、原始字段展示
          │
        SQLite mode=ro               五个课程库 + 一个树洞评测库
        SQLite 可写                  留言板库 + 访问统计库 + 账户库（服务器状态目录，不入仓库）
```

- `app.py` 是唯一后端模块，所有数据库路径从仓库根目录解析。
- 五个课程库按学期和本研学段组合；API 使用 `a/r/u/g/s` 前缀区分详情 ID。
- 树洞评测库分开保存评测列表条目和完整快照回复，使首页检索保持精确、详情查看保持完整。
- 课程列表与评测搜索各使用最多 32 项的进程内缓存；数据库文件或 WAL 变化后自动失效，课程修正标记仍实时读取。收藏与课表共用首页的课程聚合逻辑，统一地点、时间和类别显示。
- 留言板、访问统计与账户数据保存在服务器状态目录的三个独立 SQLite 库；六个正式库保持只读。
- 六个正式数据库均受版本控制，其中秋季本科、秋季研究生和树洞评测三库由 Git LFS 管理；课程源 JSON、建库脚本、抓取脚本和翻译脚本各有独立说明。
- 生产由 Nginx 终止 TLS，systemd 运行 Uvicorn，唯一更新入口是 `deploy/update.sh`。

API 速查：

| Endpoint | 用途 |
|---|---|
| `GET /api/filters` | 返回指定学期的筛选选项 |
| `GET /api/courses` | 课程搜索、筛选、排序和分页 |
| `GET /api/courses/{id}` | 根据带命名空间 ID 返回课程详情 |
| `GET /api/reviews` | 返回筛选后的评测主题和相关回复 |
| `GET /api/reviews/{pid}` | 返回已命中主题的完整主帖及快照回复 |
| `GET /api/review-courses` | 返回热门课程及课程名建议数据 |
| `GET /api/reviews/meta` | 返回评测日期、数量和快照覆盖信息 |
| `GET /api/messages` | 返回公开留言列表，按时间倒序分页 |
| `POST /api/messages` | 发布一条公开留言 |
| `GET /api/messages/{message_id}/replies` | 按 `before_id` 游标分页读取某条留言的回复，最新在前 |
| `POST /api/messages/{message_id}/replies` | 回复已有留言，body 为 `{content}`，昵称由服务器按当前登录状态确定 |
| `GET /api/changelog` | 返回两页共用的中文更新日志 |
| `GET /api/stats` | 返回今日/近 7 天/累计访问量与访客数及每日趋势 |
| `GET /api/account` | 返回当前登录状态、用户名、昵称、密保问题、收藏列表和收藏夹 |
| `POST /api/account/nickname` | 登录后修改昵称，body 为 `{nickname}` |
| `POST /api/auth/register` | 注册账号并登录，body 含用户名、密码和密保问题 |
| `POST /api/auth/login` | 用户名密码登录，签发会话 cookie |
| `POST /api/auth/logout` | 退出登录并失效当前会话 |
| `POST /api/auth/password` | 校验当前密码后修改密码，其它设备需重新登录 |
| `POST /api/auth/questions` | 校验当前密码后整体替换密保问题 |
| `POST /api/auth/reset/questions` | 按用户名返回密保问题列表，用于找回密码 |
| `POST /api/auth/reset` | 答对任意一个密保问题后重置密码 |
| `POST /api/auth/delete` | 校验密码后删除账号及其收藏、密保和会话 |
| `GET /api/favorites` | 返回当前账号的收藏列表和收藏夹 |
| `POST /api/favorites` | 按课程 ID 加入收藏并放进默认收藏夹，快照由服务器从课程库生成 |
| `POST /api/favorites/remove` | 按稳定键移除一条收藏，幂等 |
| `POST /api/favorites/set-collections` | 整体设置一条收藏所属的收藏夹，清空即取消收藏 |
| `POST /api/collections` | 新建一个自定义收藏夹 |
| `POST /api/collections/rename` | 重命名收藏夹 |
| `POST /api/collections/remove` | 删除自定义收藏夹并取消仅属于它的收藏 |
| `GET /api/health` | 校验六个数据库及关键数据契约 |

完整参数、ID、列表合并和只读安全契约见 [CLAUDE.md](CLAUDE.md)。

## 网页设计

### 视觉语言

- 两个页面共享安静、信息优先的产品风格，最大内容宽度为 `1120px`。
- 正文字体使用苹方、冬青黑体和系统无衬线字体回退；课程号、树洞号、楼层与统计数字使用 JetBrains Mono 或系统等宽字体。
- 中性色背景承载高密度信息，品牌主色为薄荷青绿；课程类型、评测实体和卡片边框使用可区分的靛蓝、绿色、琥珀、玫红等辅助色。
- 课程页顶部使用青绿与靛蓝柔光，评测页使用粉色与雾蓝柔光；浅色和深色主题分别调校对比度。
- 标题可使用克制的品牌渐变，搜索框、筛选器和内容卡片保持清晰实体边界，避免装饰遮挡文本。
- 导航与菜单采用轻玻璃、高光边缘和柔和阴影；按钮提供短促按压反馈，浮层统一轻柔进入。手机降低顶栏模糊强度，关闭背景漂移与批量卡片入场，并响应系统的减少动态、减少透明度和增强对比度偏好。

### 页面结构

- 课程页由吸顶工具栏、品牌标题、学期分段控件、搜索框、筛选区、结果工具栏、课程卡片、详情弹窗和收藏面板组成。
- 课程卡片按公选、通识、专业和研究生类型使用不同颜色的完整边框；课程详情在站内模态框中展示。
- 评测页沿用相同字体、宽度、搜索框和学期控件比例。树洞卡片使用六组轮换的完整彩色边框，不使用左侧彩条。
- 评测正文中的课程全称、教师全称和高置信缩写使用稳定颜色高亮；正文始终作为文本节点安全分段。
- 完整树洞弹窗使用独立滚动区，桌面端居中，手机端靠近底部并尽量利用可视高度。

### 响应式与无障碍

- 筛选网格从四列逐步缩为三列和两列；`720px` 以下使用居中、全宽的筛选按钮折叠筛选区。
- `640px` 以下三个学期入口每行两个，树洞课程评测入口暂时隐藏，兼容 `390px` 和 `320px` 窄屏。
- 所有固定控件具有稳定尺寸，长课程名、院系名和标签允许安全换行，不产生横向滚动。
- 卡片支持 Enter/Space，弹窗支持 Escape、背景点击、焦点锁定、背景 `inert` 和关闭后的焦点恢复。
- 图标按钮提供 `aria-label` 或 `title`；主题、搜索和筛选 URL 状态在刷新后可恢复，界面固定中文。

前端实现均位于 [index.html](index.html) 和 [reviews.html](reviews.html)，修改视觉或交互后需同时检查浅色/深色、桌面/手机、键盘操作、横向溢出和浏览器控制台。

## 数据与隐私

- 课程数据是抓取日期对应的选课网快照，不代表实时余量或实时教室安排。
- 课程数据库只读打开，应用请求不能修改课程或评测数据。
- 留言板内容与发言时昵称完全公开；未登录统一显示“路过的 PKUer”，不公开登录用户名或账号标识。来源 IP 仅以哈希形式用于发布频率限制，不对外展示。
- 访问统计只保存按北京时间分日的访问量与去重访客数，来源 IP 仅以哈希形式用于当日去重，不记录身份，也不对外展示。
- 账号保存用户名、昵称、密码哈希、密保问题文本、密保答案哈希和收藏的课程快照；密码与答案使用 `scrypt` 加盐哈希，不收集邮箱、手机号或身份信息。
- 注册、登录失败、找回密码与收藏写入的来源 IP 仅以哈希形式用于频率限制，两天后自动清除；会话令牌只保存哈希，任何响应都不包含这些字段。
- 账号可以随时在收藏面板中删除，删除后收藏、密保与会话一并清除。
- 树洞评测源快照不进入仓库；仓库只保存经过筛选和隐私清理的 SQLite 成品。
- 完整树洞仅指输入快照中保存的主帖和回复。源 manifest 的回复缓存覆盖率为 `95.24%`，未缓存回复无法展示。
- 自动分类和实体识别可能存在遗漏，页面底部保留该限制说明。

## 本地运行

仓库内 `venv/` 面向生产目录，不适合作为 macOS 开发环境。使用临时虚拟环境：

```bash
python3 -m venv /tmp/pinhaoke-dev
/tmp/pinhaoke-dev/bin/python -m pip install -r requirements.txt
/tmp/pinhaoke-dev/bin/python -m uvicorn app:app --host 127.0.0.1 --port 8000 --reload
```

访问 [http://127.0.0.1:8000/](http://127.0.0.1:8000/) 使用课程搜索，访问 [http://127.0.0.1:8000/reviews](http://127.0.0.1:8000/reviews) 使用树洞课程评测。不要直接双击 HTML 文件，页面依赖 `/api/*` 后端。

运行完整测试：

```bash
python3 -m unittest discover -s tests -v
```
